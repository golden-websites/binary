# آموزش سیستم اعداد دودویی (Binary Learning)

یک وب‌سایت آموزشی و تعاملی برای یادگیری **سیستم اعداد دودویی (Binary / Base 2)** از پایه.

این پروژه با HTML، CSS و JavaScript خالص ساخته شده و بدون نیاز به فریم‌ورک یا وابستگی خارجی اجرا می‌شود.

## ✨ امکانات

- 📚 آموزش مفاهیم پایه‌ی سیستم اعداد و مبنای ۲
- 🔢 توضیح ارزش مکانی بیت‌ها و توان‌های ۲
- 🧮 آموزش تبدیل **باینری به ده‌دهی**
- 🔄 آموزش تبدیل **ده‌دهی به باینری**
- 👣 نمایش مرحله‌به‌مرحله‌ی تبدیل ده‌دهی به باینری
- 🎮 بخش بازی اعداد دودویی با نمونه‌های ۴ بیتی
- 🔧 مبدل تعاملی اعداد باینری و ده‌دهی
- 💡 نمایش ارزش هر بیت به‌صورت تعاملی
- 📝 آزمون تصادفی برای تمرین و ارزیابی یادگیری
- ❌ آموزش اشتباهات رایج هنگام کار با اعداد دودویی
- 🌓 پشتیبانی از حالت روشن و تاریک
- 💾 ذخیره‌ی انتخاب تم در مرورگر
- 📱 طراحی واکنش‌گرا برای نمایشگرهای مختلف
- ♿ توجه به دسترس‌پذیری و پشتیبانی از `prefers-reduced-motion`
- 🇮🇷 رابط کاربری کاملاً فارسی و راست‌به‌چپ

## 🛠️ تکنولوژی‌های استفاده‌شده

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **BigInt** برای انجام محاسبات دقیق اعداد بزرگ
- **LocalStorage** برای ذخیره‌ی تنظیمات تم

این پروژه از هیچ فریم‌ورک JavaScript یا کتابخانه‌ی خارجی برای اجرای اصلی سایت استفاده نمی‌کند.

## 🧩 بخش‌های JavaScript

### `converter.js`

منطق مربوط به تبدیل اعداد را پیاده‌سازی می‌کند:

- تبدیل Binary → Decimal
- تبدیل Decimal → Binary
- اعتبارسنجی ورودی‌ها
- نمایش مراحل تقسیم بر ۲
- پشتیبانی از اعداد بزرگ با `BigInt`
- کپی کردن نتیجه در Clipboard

### `bit-visualizer.js`

برای نمایش تعاملی بیت‌ها استفاده می‌شود و امکان مشاهده و تغییر وضعیت بیت‌های یک عدد دودویی را فراهم می‌کند.

### `quiz.js`

سیستم آزمون تصادفی سایت را مدیریت می‌کند.

سؤال‌ها در چند دسته تولید می‌شوند:

- تبدیل باینری به ده‌دهی
- تبدیل ده‌دهی به باینری
- ارزش یک بیت
- ارزش مکانی توان‌های ۲

برای هر سؤال چهار گزینه‌ی متفاوت ارائه می‌شود و پس از پاسخ، توضیح پاسخ صحیح نیز نمایش داده می‌شود.

### `theme.js`

سیستم تم سایت را مدیریت می‌کند.

- تشخیص خودکار حالت روشن یا تاریک سیستم
- امکان تغییر دستی تم
- ذخیره‌ی انتخاب کاربر در `localStorage`

## 🧠 مباحث آموزشی

محتوای آموزشی سایت شامل موارد زیر است:

1. معرفی سیستم‌های عددی
2. سیستم اعداد دودویی
3. ارزش مکانی بیت‌ها
4. تبدیل باینری به ده‌دهی
5. تبدیل ده‌دهی به باینری
6. کاربردهای سیستم دودویی
7. تمرین و آزمون
8. اشتباهات رایج در محاسبات باینری

برای مثال، سایت تبدیل عدد زیر را به‌صورت مرحله‌ای توضیح می‌دهد:

```text
1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11₁₀
```

## 🌐 ویژگی‌های فنی

### پشتیبانی از اعداد بزرگ

برای جلوگیری از محدودیت محاسبات معمول JavaScript، بخش تبدیل باینری از `BigInt` استفاده می‌کند.

مبدل باینری ورودی‌هایی تا **۶۴ بیت** را می‌پذیرد و مبدل ده‌دهی نیز اعداد صحیح نامنفی تا **۱۸ رقم** را پشتیبانی می‌کند.

### پشتیبانی از اعداد فارسی

ورودی‌های عددی می‌توانند با ارقام فارسی یا عربی نیز وارد شوند و سایت آن‌ها را به ارقام لاتین تبدیل می‌کند.

برای مثال:

```text
۱۰۱۱
```

و

```text
1011
```

هر دو قابل پردازش هستند.
